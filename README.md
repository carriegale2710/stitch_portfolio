# Developer Portfolio

This is a developer portfolio project that showcases my skills, projects, and experience in web development.

## Tech stack

- HTML
- CSS
- JS
- Tailwind CSS

## Other tools

- Google Stitch (UI)
- Figma (UI)

## Features

- Minimalist site: 1-3 pages max
- Custom design system
- Cyberpunk aesthetic
- Hover animations
- Clear sections

## Design Decisions

- The portfolio is designed to be simple, fast, responsive and visually appealing.
- I decided to keep the MVP to one main page for now - recruiters only have 10 seconds to scan your portfolio, so extra pages would not work well here.
- Initial MVP prototype and custom Design system designed and generated with Google stitch. Advantages was that I could attach images from my moodboard to explore different visual mockups for quick comparison. Plan is to treat it as a strong starting point and build on extra functionality on top of it.
- Originally created a previous portfolio website in React, however this added unneccessary bloat and slowed loading times, so switching to vanilla HTML/CSS and JS is intentional to keep things simple and easier to maintain long term. Also lowers risks of bugs + better SEO.
