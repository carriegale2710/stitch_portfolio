# Developer Portfolio

- This is a developer portfolio project that showcases my skills, projects, and experience in web development.
- The portfolio is built using HTML, CSS (+ Tailwind), and JavaScript, and it is designed to be responsive and visually appealing.
- Initial MVP prototype and custom Design system generated with Google stitch. Plan is to build on top of it.

## Features

- Custom design system
- JS animations
- Clear sections
- Visually aesthetic UI - minimalist cyberpunk theme
